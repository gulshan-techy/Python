## Simple Calculator

### Description
A Python program that performs basic arithmetic operations (addition, subtraction, multiplication, and division) on two user-provided numbers.

### Supported Operations
- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)

### Concepts Covered
- User input using `input()`
- Type conversion using `float()`
- Conditional statements (`if-elif-else`)
- Arithmetic operators
- Nested conditional statements
- Error handling through input validation

### How It Works
1. Accept two numbers from the user.
2. Ask the user to select an arithmetic operator.
3. Use conditional statements to identify the selected operation.
4. Perform the corresponding calculation.
5. Handle division by zero and invalid operators.
6. Display the calculation result.

### Example Output

```text
Enter your first number: 10
Enter your second number: 5
Enter the operation (+, -, *, /): *
Result: 50.0
```

### Learning Outcome
This exercise demonstrates how to build a basic calculator using Python variables, user input, arithmetic operators, and conditional logic.
