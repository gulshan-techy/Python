## Part 6: Right-Aligned Triangle Star Pattern

### Description
A Python program that prints a right-aligned triangle using stars (`*`). Each row contains one more star than the previous row, while the leading spaces decrease.


### Concepts Covered
- `for` loops and `range()`
- Arithmetic expressions
- String repetition using `*`
- String concatenation using `+`
- Output alignment with spaces

### How It Works
1. Set the number of rows to 5.
2. Iterate from 1 to the specified number of rows.
3. Calculate the leading spaces as `num - i`.
4. Calculate the stars for each row as `i`.
5. Combine the spaces and stars to print the right-aligned pattern.

### Learning Outcome
This exercise demonstrates how loops, arithmetic expressions, and string repetition can be used to control the alignment of a pattern.
