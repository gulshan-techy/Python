# Python Pattern Programs

## Part 1: Square Star Pattern

### Description
This Python program prints a square pattern using stars (`*`). It uses nested `for` loops to print 5 rows, each containing 5 stars.

### Concepts Covered
- `for` loops
- Nested loops
- The `range()` function
- The `print()` function
- The `end` parameter in `print()`

### How It Works
1. The outer loop runs 5 times, creating 5 rows.
2. The inner loop runs 5 times for each row, printing 5 stars.
3. `end=" "` keeps the stars on the same line with spaces between them.
4. The empty `print()` moves the output to the next line after each row.

### Learning Outcome
This exercise demonstrates how nested loops work together to create patterns in Python. It is the first program in my Python Pattern Practice series.
