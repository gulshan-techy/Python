## Squares of Numbers

### Description

A Python program that calculates and displays the square of each number from 1 up to a user-defined limit.

### Concepts Covered

* User input using `input()` and `int()`
* `for` loops and `range()`
* Conditional statements
* Arithmetic operators
* Formatted strings using f-strings

### How It Works

1. Accept a positive integer from the user.
2. Iterate from 1 to the given number.
3. Multiply each number by itself to calculate its square.
4. Display each number and its square.

### Example Output

```
How many squares do you want? 5
1 * 1 = 1
2 * 2 = 4
3 * 3 = 9
4 * 4 = 16
5 * 5 = 25
```

### How to Run

```
python loops/squares_of_numbers.py
```

### Learning Outcome

This exercise strengthens understanding of loops, arithmetic operations, input validation, and formatted output in Python.
