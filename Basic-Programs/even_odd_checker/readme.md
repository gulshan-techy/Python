# 🐍 Even or Odd Number Checker in Python

## 📌 About the Project

This is a beginner-friendly Python program that checks whether a number entered by the user is even or odd.

The program uses an `if-else` conditional statement and the modulo (`%`) operator to determine whether the number is divisible by 2.

## 🎯 Concepts Covered

- `input()` — Taking input from the user.
- `int()` — Converting user input into an integer.
- `if-else` — Making decisions based on a condition.
- Modulo (`%`) operator — Finding the remainder after division.
- `print()` — Displaying the result.

## 💻 Python Code

```
num = int(input("Enter A Number: "))

if num % 2 == 0:
    print(num, "is Even Number")
else:
    print(num, "is Odd Number")
```

**Example 2: Odd Number**
