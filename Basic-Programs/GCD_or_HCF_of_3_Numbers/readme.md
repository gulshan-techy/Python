## HCF of Three Numbers

### Description
A Python program that finds the Highest Common Factor (HCF), also known as the Greatest Common Divisor (GCD), of three positive integers.

### Concepts Covered
- User input using `input()` and `int()`
- Finding the minimum value using `min()`
- `for` loops and `range()`
- Modulus operator (`%`)
- Conditional statements and logical operators

### How It Works
1. Accept three integers from the user.
2. Find the smallest of the three numbers.
3. Check each integer from 1 to the smallest number.
4. Identify numbers that divide all three inputs without a remainder.
5. Store the largest common factor and display the result.

### Example Output

```
Enter first number: 12
Enter second number: 18
Enter third number: 24
HCF of the three numbers is: 6
```

### Learning Outcome
This exercise demonstrates how to find common factors using loops, conditional statements, and the modulus operator in Python.
