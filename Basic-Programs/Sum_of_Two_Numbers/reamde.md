# 🐍 Addition of Two Numbers in Python

## 📌 About the Project

This is a beginner-friendly Python program that takes two numbers as input from the user and calculates their sum.

The purpose of this program is to understand basic Python concepts such as user input, type conversion, variables, arithmetic operators, and output.

## 🎯 Concepts Covered

* `input()` — Accepting user input.
* `int()` — Converting input into integers.
* Variables — Storing values in variables.
* Arithmetic Operators — Using the `+` operator.
* `print()` — Displaying the result.

## 💻 Python Code

```
a = int(input("First number: "))

b = int(input("Second number: "))

total = a + b

print("Sum of numbers:", total)
```

## ▶️ Sample Output

```
First number: 10
Second number: 20
Sum of numbers: 30
```

## ⚙️ How to Run

**Step 1:** Make sure Python 3 is installed on your system.

**Step 2:** Open a terminal in the project directory.

**Step 3:** Run the program:

```
python add_two_numbers.py
```

Depending on your system, you may need to use `python3` instead of `python`.
