## Find All Divisors of a Number

### Description

A Python program that finds and displays all divisors of a positive integer entered by the user.

### Concepts Covered

* User input using `input()` and `int()`
* `for` loops and `range()`
* Conditional statements (`if-else`)
* Modulus operator (`%`)
* Lists and the `append()` method

### How It Works

1. Accept a positive integer from the user.
2. Check each integer from 1 to the given number.
3. Use the modulus operator to determine whether each integer divides the number exactly.
4. Add all divisors to a list.
5. Display the complete list of divisors.

### Example Output

```
Enter a positive integer: 12
Divisors of 12 are: [1, 2, 3, 4, 6, 12]
```

### How to Run

```
python loops/find_all_divisors.py
```

### Learning Outcome

This exercise strengthens understanding of loops, divisibility, conditional logic, and list operations in Python.
