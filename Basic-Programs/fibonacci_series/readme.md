## Fibonacci Series

### Description

A Python program that prints the Fibonacci series up to the number of terms specified by the user.

### Concepts Covered

* User input using `input()` and `int()`
* Conditional statements (`if-else`)
* `for` loops and `range()`
* Multiple assignment
* Updating variables in each iteration

### How It Works

1. Accept the number of terms from the user.
2. Validate that the number of terms is positive.
3. Initialize the first two Fibonacci numbers as 0 and 1.
4. Use a loop to print the current number.
5. Update both variables so the next number is the sum of the previous two numbers.

### Example Output

```
Enter how many terms you want: 7
Fibonacci Series:
0 1 1 2 3 5 8
```

### How to Run

```
python loops/fibonacci_series.py
```

### Learning Outcome

This exercise demonstrates loops, variable updates, multiple assignment, and the logic behind generating a mathematical sequence in Python.
