## Kilometers to Miles Converter

### Description

A Python program that converts a distance from kilometers to miles using a standard conversion factor.

### Conversion Formula

Miles = Kilometers × 0.621371

### Concepts Covered

* User input using `input()`
* Type conversion using `float()`
* Arithmetic operations
* Conditional statements
* Formatted strings (f-strings)
* Decimal formatting using `:.2f`

### How It Works

1. Accept a distance in kilometers from the user.
2. Check whether the distance is negative.
3. Multiply the distance by 0.621371 to calculate miles.
4. Display the converted distance rounded to two decimal places.

### Example Output

```
Enter distance in kilometers: 10
10.00 kilometers is equal to 6.21 miles.
```

### How to Run

```
python basic-operations/kilometers_to_miles.py
```

### Learning Outcome

This exercise demonstrates how to accept decimal input, perform mathematical calculations, validate input, and format output in Python.
